# Трёхмерная PIC/FDTD-модель и демонстрация излучения Черенкова

## Что реализовано

Проект дополнен минимальным замкнутым циклом электромагнитного метода
Particle-in-Cell (PIC):

1. поля хранятся на трёхмерной разнесённой сетке Йи;
2. электрическое и магнитное поля интерполируются в положение частицы;
3. импульс частицы обновляется релятивистским методом Бориса;
4. координата обновляется со скоростью `v = p/(gamma*m)`;
5. заряд и ток осаждаются обратно на сетку;
6. поля обновляются с учётом вещества;
7. на стенках задаются отражающие граничные условия идеального проводника;
8. частица, покинувшая расчётную область, удаляется;
9. компоненты полей, ток, заряд и частицы записываются в HDF5;
10. добавлен сценарий прохождения релятивистского электрона через однородный
    диэлектрик выше порога излучения Черенкова.

Основные файлы:

| Файл | Назначение |
|---|---|
| `YeeGrid3D.hpp` | размеры и индексация разнесённой сетки Йи |
| `Field3D.hpp` | массивы `E`, `B`, `J` и `rho` |
| `Geometry3D.hpp` | материалы, однородный фон и объекты-параллелепипеды |
| `Solver3D.hpp` | FDTD, pusher, интерполяция, осаждение и границы |
| `Hdf5Writer.hpp` | запись снимков в HDF5 |
| `main.cpp` | полный временной цикл и опыт Черенкова |
| `plot_cherenkov.py` | построение среза поля из HDF5 |
| `tests.cpp` | автоматические проверки |

## Один шаг программы

Метод `Solver3D::step()` выполняет операции в следующем порядке:

```text
E^n, B^(n-1/2), x^n, p^(n-1/2)
                  |
                  v
1. updateMagneticField()
2. PEC-условия для B
3. интерполяция E и B к частицам
4. релятивистский Boris pusher
5. перемещение или поглощение частиц
6. осаждение rho^(n+1) и J^(n+1/2)
7. updateElectricField()
8. PEC-условия для E
                  |
                  v
E^(n+1), B^(n+1/2), x^(n+1), p^(n+1/2)
```

В классе также обновляются физическое время `time`, номер шага `stepNumber`,
счётчик поглощённых частиц и их суммарный заряд.

## Интерполяция полей и релятивистский pusher

Каждая компонента поля расположена в своей точке сетки Йи. Функция `sample()`
учитывает соответствующий сдвиг компоненты и выполняет трилинейную CIC-
интерполяцию восьми соседних значений.

Частица хранит физический импульс `p`, а не скорость. Используются соотношения

```text
gamma = sqrt(1 + |p|^2/(m^2*c^2)),
v = p/(gamma*m).
```

Релятивистский алгоритм Бориса разделяет действие силы Лоренца на половину
электрического толчка, магнитное вращение и вторую половину электрического
толчка. Фактор `gamma` для магнитного вращения вычисляется по промежуточному
импульсу. Благодаря этому чистое магнитное поле изменяет направление импульса,
но не его модуль, а вычисленная скорость остаётся меньше `c`.

Реализация соответствует стандартной структуре релятивистского Boris pusher;
современный анализ таких интеграторов приведён в статье Higuera и Cary
[[1]](#references).

## Осаждение заряда и тока

Заряд осаждается в узлы сетки CIC-весами. Простое независимое осаждение
`J = q*v` не гарантирует выполнения дискретного уравнения непрерывности:

```text
(rho_new - rho_old)/dt + div(J) = 0.
```

Поэтому перед pusher сохраняется старое положение частицы, после чего
`shapeChange()` строит старые CIC-веса и их изменение. Методы
`depositCurrentX/Y/Z()` используют разложение плотности Эзиркепова и дискретно
интегрируют полученные изменения вдоль соответствующей координаты. Это связывает
изменение `rho` и осаждённый `J` одной формулой, а не двумя независимыми
интерполяциями. Основа метода описана в статье Эзиркепова [[2]](#references).

Автоматический тест перемещает частицу через границы ячеек одновременно по трём
координатам. Относительная невязка дискретного уравнения непрерывности остаётся
на уровне ошибки округления (`< 1e-14`).

## Границы частиц

По умолчанию используется `ParticleBoundaryCondition::Absorb`:

- траектория обрезается в первой точке пересечения стенки;
- ток осаждается до этой точки;
- частица удаляется из `particles`;
- её заряд сохраняется как неподвижный поверхностный заряд на проводящей стенке.

Последний пункт важен: простое удаление частицы уничтожило бы заряд и нарушило
уравнение непрерывности. Поверхностный заряд повторно добавляется в `rho` на
последующих шагах. Для отладочных задач оставлен режим `Reflect`, в котором
нормальная компонента импульса меняет знак.

## Отражающие границы полей

На всех шести гранях используются условия идеального электрического проводника
(PEC):

```text
n x E = 0,
n dot B = 0.
```

То есть тангенциальные компоненты `E` и нормальная компонента `B` обнуляются.
Магнитные условия применяются сразу после шага Фарадея, электрические — после
шага Ампера. Волна отражается от стенки. Такое размещение компонент и способ
задания проводящих границ основаны на FDTD-схеме Йи [[3]](#references).

## Геометрия и вещества

`Material` содержит:

- относительную диэлектрическую проницаемость `relativePermittivity`;
- относительную магнитную проницаемость `relativePermeability`;
- проводимость `conductivity`.

`Geometry3D` задаёт фоновый материал для всей области. Метод `addBox()` позволяет
добавлять прямоугольные объекты; последний добавленный объект имеет приоритет.
В демонстрации используется только однородный фон.

Обновление электрического поля решает дискретную форму

```text
epsilon*dE/dt + sigma*E = curl(H) - J,
H = B/mu.
```

Член проводимости интегрируется полунеявно. Для неоднородной геометрии `epsilon`
берётся в точке соответствующей компоненты `E`, а `mu` — в точках компонент
`B`. Для текущего однородного теста это сводится к обычной волновой скорости
`c/n`, где `n = sqrt(epsilon_r*mu_r)`.

## HDF5

`Hdf5Writer` создаёт сжатый бинарный файл следующей структуры:

```text
/grid
    attributes: nx, ny, nz, lx, ly, lz, dx, dy, dz, n
    relative_permittivity[nz, ny, nx]
    relative_permeability[nz, ny, nx]
/steps/00000000
/steps/00000015
    attributes: step, time, particle_count
    Ex, Ey, Ez
    Bx, By, Bz
    Jx, Jy, Jz
    rho
    E_magnitude_xy[ny, nx]
    particles[N, 8] = x,y,z,px,py,pz,q,m
```

Полные трёхмерные массивы сохраняют естественные размеры разнесённой сетки.
Дополнительный двумерный массив `E_magnitude_xy` удобен для быстрого просмотра.
Данные сжимаются встроенным фильтром DEFLATE.

## Опыт с излучением Черенкова

Использованы параметры:

| Параметр | Значение |
|---|---:|
| сетка | `96 x 48 x 48` |
| шаг сетки | `1 mm` |
| `epsilon_r` | `2.25` |
| `mu_r` | `1` |
| показатель преломления `n` | `1.5` |
| скорость электрона | `beta = 0.99` |
| кинетическая энергия электрона | `3.111 MeV` |
| вес макрочастицы | `10^6` электронов |
| число шагов | `180` |
| шаг времени | `1.82954e-12 s` |

Порог равен

```text
beta > 1/n = 0.6667.
```

Условие выполнено. Теоретический угол конуса:

```text
cos(theta) = 1/(n*beta),
theta = 47.67 degrees.
```

Именно зависимость угла от скорости и показателя преломления является основным
признаком эффекта Черенкова; экспериментальная работа Черенкова и теория
Франка–Тамма приведены в [[4]](#references) и [[5]](#references).

Полный запуск завершён успешно. Частица была поглощена правой стенкой между
сохранёнными шагами 150 и 165. Созданы:

- `output/cherenkov.h5` — 69 МБ, полные поля и источники;
- `output/cherenkov_step150.png` — срез модуля электрического поля;
- `output/cherenkov_bz_step150.png` — знакопеременный срез `Bz`.

На изображение нанесены теоретические образующие конуса с углом `47.7°`.

## Сборка и запуск

Зависимости для Ubuntu/Debian:

```bash
sudo apt-get install cmake libhdf5-dev python3-h5py python3-matplotlib
```

Сборка и тесты:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Короткий отладочный запуск:

```bash
./build/pic3d --quick --output output/cherenkov_quick.h5
```

Полный запуск:

```bash
./build/pic3d --output output/cherenkov.h5
```

Построение рисунка до поглощения частицы:

```bash
python3 plot_cherenkov.py output/cherenkov.h5 \
    --step 150 --quantity e --output output/cherenkov_step150.png

python3 plot_cherenkov.py output/cherenkov.h5 \
    --step 150 --quantity bz --output output/cherenkov_bz_step150.png
```

## Проверки

В `tests.cpp` проверяются:

- выбор фонового материала и материала объекта;
- точное дискретное сохранение заряда при движении между ячейками;
- сохранение заряда при поглощении частицы стенкой;
- удаление поглощённой частицы и счётчики поглощения;
- PEC-условия для электрического поля;
- PEC-условия для магнитного поля;
- изменение коэффициента обновления поля в однородном диэлектрике.

Дополнительно полный запуск подтвердил создание HDF5, чтение его через `h5py`,
построение PNG и поглощение частицы.

## Ограничения первой версии

Этот расчёт демонстрирует работоспособность численного контура и качественный
конический фронт, но пока не является прецизионным расчётом спектра Черенкова:

1. диэлектрик недисперсионный и не имеет частотной зависимости `epsilon`;
2. PEC-стенки отражают волны; для открытой области нужна PML;
3. начальное поле не получается из решения уравнения Пуассона для заряда;
4. используется одна макрочастица, поэтому заметны сеточные и статистические
   артефакты;
5. CIC-форма и конечный шаг сетки ограничивают разрешаемый спектр;
6. на неоднородных границах материалов потребуются более строгие правила
   усреднения параметров;
7. для количественной проверки нужно измерить угол по максимумам поля на серии
   сеток и показать сеточную сходимость.

Следующий физически осмысленный этап: добавить PML, дисперсионную модель
вещества, согласованную инициализацию поля и автоматическое измерение угла
конуса с исследованием сходимости.
